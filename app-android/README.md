# Aplicativo Oficial — Seleção de Baixa Grande

Este diretório contém o projeto Android/APK do aplicativo da Seleção de Baixa Grande.

- Projeto Android: `app-android/`
- APK gerado: `Seleção De Baixa Grande.apk`
- Pacote: `br.com.selecaobaixagrande.app`
- O aplicativo é separado da estrutura das páginas do site, mesmo estando neste mesmo repositório.

## Build

O APK de release é gerado automaticamente pelo GitHub Actions em cada push que alterar `app-android/**`.
